# CLI (004)

```text
surfclip analyse-rides VIDEO [--cpu]                 # analysis stage (named riders' rides)
surfclip reference add VIDEO                         # import a reference clip (probe..track)
surfclip reference pick VIDEO --at T --x X --y Y     # choose the surfer and analyse
surfclip eval-score [--json]                         # SC-002 over sessions with stars
surfclip models download                             # also fetches the pose weights
```
